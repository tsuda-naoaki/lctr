4.2.2 Representational coordinates obtained from global order-coordinate quotients

The global order-coordinate quotient sends each incomparability class in the entire canonical comparison quotient to a single order-coordinate class. The comparison representational coordinate derived from ℭ/𝔇\mathfrak{C}/\mathfrak{D} is determined by composing the canonical global order-coordinate projection with an order embedding into the selected linearly ordered codomain.

Definition 4.137 (Strict order embedding).

For strictly ordered sets (S,<S)(S\mathchar 44\relax\allowbreak<_{S}) and (T,<T)(T\mathchar 44\relax\allowbreak<_{T}), and an injection f:S↪Tf:S\hookrightarrow T, define the strict-order-embedding condition by

𝖮𝗋𝖽𝖤𝗆𝖻⁢(f;S,<S;T,<T)⟺f∗⁢(<T)=<S\mathsf{OrdEmb}\left(f;S\mathchar 44\relax\allowbreak<_{S};T\mathchar 44\relax% \allowbreak<_{T}\right)\Longleftrightarrow f^{\ast}(<_{T})=<_{S}
Lemma 4.138 (Composition of a quotient projection and an order embedding).

Take sets S,Q,VS\mathchar 44\relax\allowbreak Q\mathchar 44\relax\allowbreak V; on SS, take relations ≍,≺\asymp\mathchar 44\relax\allowbreak\prec; on Q,VQ\mathchar 44\relax\allowbreak V, take strict orders <Q,<V<_{Q}\mathchar 44\relax\allowbreak<_{V}, a map π\pi, and an injection ι:Q↪V\iota:Q\hookrightarrow V. Then the following implication holds:

π:S↠Q,𝖮𝗋𝖽𝖱𝖾𝗉𝖢𝗈𝗇𝖽⁢(π;≍,≺,<Q),𝖮𝗋𝖽𝖤𝗆𝖻⁢(ι;Q,<Q;V,<V),⟹f:=ι∘π:S⟶V,𝖮𝗋𝖽𝖱𝖾𝗉𝖢𝗈𝗇𝖽⁢(f;≍,≺,<V)\begin{gathered}\pi:S\twoheadrightarrow Q\mathchar 44\relax\allowbreak\qquad% \mathsf{OrdRepCond}(\pi;\asymp\mathchar 44\relax\allowbreak\prec\mathchar 44% \relax\allowbreak<_{Q})\mathchar 44\relax\allowbreak\\ \mathsf{OrdEmb}\left(\iota;Q\mathchar 44\relax\allowbreak<_{Q};V\mathchar 44% \relax\allowbreak<_{V}\right)\mathchar 44\relax\allowbreak\\[3.0pt] \Longrightarrow\\[-2.0pt] f:=\iota\circ\pi:S\longrightarrow V\mathchar 44\relax\allowbreak\\ \mathsf{OrdRepCond}(f;\asymp\mathchar 44\relax\allowbreak\prec\mathchar 44% \relax\allowbreak<_{V})\end{gathered}
Proof.

Injectivity of ι\iota gives 𝖤𝗊𝖪𝖾𝗋⁢(f)=𝖤𝗊𝖪𝖾𝗋⁢(π)\mathsf{EqKer}(f)=\mathsf{EqKer}(\pi). Preservation and reflection of strict order give f∗⁢(<V)=π∗⁢(<Q)f^{\ast}(<_{V})=\pi^{\ast}(<_{Q}). Apply the assumed 𝖮𝗋𝖽𝖱𝖾𝗉𝖢𝗈𝗇𝖽⁢(π;≍,≺,<Q)\mathsf{OrdRepCond}(\pi;\asymp\mathchar 44\relax\allowbreak\prec\mathchar 44% \relax\allowbreak<_{Q}) and Definition 4.108. ∎

Lemma 4.139 (Quotient-order embedding for nested domains).

Let A⊆SA\subseteq S, let QA,QSQ_{A}\mathchar 44\relax\allowbreak Q_{S} carry strict orders <A,<S<_{A}\mathchar 44\relax\allowbreak<_{S}, and let πA:A↠QA\pi_{A}:A\twoheadrightarrow Q_{A} and πS:S↠QS\pi_{S}:S\twoheadrightarrow Q_{S} be surjections. Assume that both of the following equivalences hold for every x,y∈Ax\mathchar 44\relax\allowbreak y\in A:

πA⁢(x)=πA⁢(y)⟺πS⁢(x)=πS⁢(y),πA⁢(x)<AπA⁢(y)⟺πS⁢(x)<SπS⁢(y).\begin{gathered}\pi_{A}(x)=\pi_{A}(y)\Longleftrightarrow\pi_{S}(x)=\pi_{S}(y)% \mathchar 44\relax\allowbreak\\ \pi_{A}(x)<_{A}\pi_{A}(y)\Longleftrightarrow\pi_{S}(x)<_{S}\pi_{S}(y).\end{gathered}

Then the rule

ιA,S:QA↪QS,ιA,S⁢(πA⁢(x)):=πS⁢(x)(x∈A)\iota_{A\mathchar 44\relax\allowbreak S}:Q_{A}\hookrightarrow Q_{S}\mathchar 4% 4\relax\allowbreak\qquad\iota_{A\mathchar 44\relax\allowbreak S}\bigl{(}\pi_{A% }(x)\bigr{)}:=\pi_{S}(x)\quad(x\in A)

defines an injection satisfying

𝖮𝗋𝖽𝖤𝗆𝖻⁢(ιA,S;QA,<A;QS,<S),ιA,S∘πA=πS|A.\mathsf{OrdEmb}\left(\iota_{A\mathchar 44\relax\allowbreak S};Q_{A}\mathchar 4% 4\relax\allowbreak<_{A};Q_{S}\mathchar 44\relax\allowbreak<_{S}\right)% \mathchar 44\relax\allowbreak\qquad\iota_{A\mathchar 44\relax\allowbreak S}% \circ\pi_{A}=\left.\pi_{S}\right|_{A}.
Proof.

Since πA\pi_{A} is surjective, every element of QAQ_{A} has the form πA⁢(x)\pi_{A}(x) for some x∈Ax\in A. By the class-judgment equivalence, πA⁢(x)=πA⁢(y)\pi_{A}(x)=\pi_{A}(y) implies πS⁢(x)=πS⁢(y)\pi_{S}(x)=\pi_{S}(y), so the value of the map is independent of the representative. By the converse class judgment, two elements with the same image satisfy πA⁢(x)=πA⁢(y)\pi_{A}(x)=\pi_{A}(y); hence ιA,S\iota_{A\mathchar 44\relax\allowbreak S} is injective. The order-judgment equivalence and the definition give

πA⁢(x)<AπA⁢(y)\displaystyle\pi_{A}(x)<_{A}\pi_{A}(y) ⟺ιA,S⁢(πA⁢(x))<SιA,S⁢(πA⁢(y)),\displaystyle\Longleftrightarrow\iota_{A\mathchar 44\relax\allowbreak S}\bigl{% (}\pi_{A}(x)\bigr{)}<_{S}\iota_{A\mathchar 44\relax\allowbreak S}\bigl{(}\pi_{% A}(y)\bigr{)}\mathchar 44\relax\allowbreak
ιA,S⁢(πA⁢(x))\displaystyle\iota_{A\mathchar 44\relax\allowbreak S}\bigl{(}\pi_{A}(x)\bigr{)} =πS⁢(x)(x∈A)\displaystyle=\pi_{S}(x)\qquad(x\in A)

and thus give preservation and reflection of strict order and the commutative identity. ∎
