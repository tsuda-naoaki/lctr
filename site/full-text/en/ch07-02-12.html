7.2.12 Input Consistency of Audit-Boundary Directed Hypergraphs

Audit-boundary directed hypergraphs are given by Definition 7.27.

The physical and mathematical boundary claims, time contents, transfer events, and reference-specific results stated in each reference are represented by a finite directed hypergraph for that reference. The input set of each hyperedge represents the set of premises used jointly to establish its output.

Audit-boundary nodes, audit-boundary support sets, and audit-boundary edges are given by Definition 7.18 and Definition 7.26.

Proposition 7.122 (Input Consistency of Audit-Boundary Directed Hypergraphs).

For each R∈𝖱𝖾𝖿auditR\in\mathsf{Ref}^{\mathrm{audit}}, the time contents, transfer events, and results correspond injectively to their respective audit-boundary nodes or audit-boundary edges. The time-content input and time-content output of each transfer edge coincide with the images of

𝖳𝗋𝖺𝗇𝗌𝖿𝖾𝗋𝖨𝗇R,ϵ,𝖳𝗋𝖺𝗇𝗌𝖿𝖾𝗋𝖮𝗎𝗍R,ϵ\mathsf{TransferIn}_{R\mathchar 44\relax\allowbreak\epsilon}\mathchar 44\relax% \allowbreak\qquad\mathsf{TransferOut}_{R\mathchar 44\relax\allowbreak\epsilon}

and the time-content input of each result edge coincides with the image of

𝖱𝖾𝗌𝗎𝗅𝗍𝖯𝗋𝖾𝗋𝖾𝗊R,η\mathsf{ResultPrereq}_{R\mathchar 44\relax\allowbreak\eta}

.

Proof.

The time-content node map, result-node map, transfer-edge node map, and result-edge node map are injective in Definition 7.18 and Definition 7.26, respectively.

The input and output maps of Definition 7.27 take

𝖭𝗈𝖽𝖾𝖮𝖿Raudit,time⁢[𝖳𝗋𝖺𝗇𝗌𝖿𝖾𝗋𝖨𝗇R,ϵ],\displaystyle\mathsf{NodeOf}^{\mathrm{audit\mathchar 44\relax\allowbreak time}% }_{R}\left[\mathsf{TransferIn}_{R\mathchar 44\relax\allowbreak\epsilon}\right]% \mathchar 44\relax\allowbreak
𝖭𝗈𝖽𝖾𝖮𝖿Raudit,time⁢[𝖳𝗋𝖺𝗇𝗌𝖿𝖾𝗋𝖮𝗎𝗍R,ϵ]\displaystyle\mathsf{NodeOf}^{\mathrm{audit\mathchar 44\relax\allowbreak time}% }_{R}\left[\mathsf{TransferOut}_{R\mathchar 44\relax\allowbreak\epsilon}\right]

as the time-content input and time-content output, respectively, for a transfer edge. The same definition takes the time-content input of a result edge to be

𝖭𝗈𝖽𝖾𝖮𝖿Raudit,time⁢[𝖱𝖾𝗌𝗎𝗅𝗍𝖯𝗋𝖾𝗋𝖾𝗊R,η]\mathsf{NodeOf}^{\mathrm{audit\mathchar 44\relax\allowbreak time}}_{R}\left[% \mathsf{ResultPrereq}_{R\mathchar 44\relax\allowbreak\eta}\right]

. Thus each correspondence holds. ∎
