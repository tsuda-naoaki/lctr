7.2.9 資料別監査表の証拠欄と局所キー

定義 7.111 (資料別監査表の証拠欄).

定義 7.109 の形式証拠記録を資料別監査表に示すとき、次の六欄を区別する。

  1. 1.

    成果の成立根拠は、資料固有成果を支える原典の定義、仮定、形式関係、操作、観測または実験を示す。

  2. 2.

    直接測定対象は、装置が直接に応答し、記録し、または比較する物理担体、物理量もしくは表示を示す。

  3. 3.

    直接測定述語は、直接測定対象について得られる値、差、率、相関、個数または関係を示す。

  4. 4.

    直接測定の条件および適用域は、その測定に必要な装置構成、較正、近似、背景条件、操作および対象範囲を示す。

  5. 5.

    形式的一般化の対象は、原典の形式構成が適用を拡張する対象または対象族を示す。この対象は、直接測定対象と同一であるとは限らない。

  6. 6.

    形式的一般化の条件および適用域は、その一般化に必要な仮定、写像、同一視、近似、背景条件および対象範囲を示す。

六欄は、成果の成立根拠、直接測定および形式的一般化を相互に代用せず、それぞれの証拠効力域を確定するために用いる。

定義 7.112 (資料別監査表の局所キー).

定義 7.92 の有限添字表において、一つの資料の一つの対応表の中だけで参照先を指定する正の整数を局所キーとよぶ。局所キーの種類を次のように区別する。

  1. 1.

    原典位置キーは、原典中の一つまたは複数の位置を参照する。

  2. 2.

    時間内容キーは、その資料について定めた時間内容添字の有限集合を参照する。

  3. 3.

    形式証拠キーは、移送または成果を支える資料形式記述の添字の有限集合を参照する。

  4. 4.

    意味成分キーは、資料形式記述から分離した意味成分の添字の有限集合を参照する。

同じ整数であっても、資料、対応表またはキーの種類が異なれば同一の参照先を表さない。各対応表は、局所キーと参照先との対応を、そのキーを用いる表より前または同じ記述単位に示す。局所キーは証拠を置き換えるものではなく、対応表を介して証拠、時間内容または意味成分を復元できる状態を保ったまま、表中の反復表示だけを短縮する。
