# LCTR v1.0.1

**時間変数を物理法則の前提から帰結へ移す：局所比較による時間成立の完全記述と破綻分類の一般理論**

Moving the Time Variable from a Premise of Physical Law to a Consequence:
A General Theory of the Complete Description of Time Establishment through
Local Comparison and Failure Classification

時間参照の局所比較理論（Local-comparison theory of time reference; LCTR）は、**非時間的な物理入力だけから物理時間を最後まで構成した、人類史上初の理論であると主張する。** その構成のどの段階でも、まだ生成していない時間量や時間的関係を前提として導入しない。

The local-comparison theory of time reference (LCTR) **claims to be the first theory in human history to construct physical time from start to finish using only nontemporal physical inputs.** At no stage does the construction presuppose temporal quantities or relations that it has not yet generated.

## 物理学への告発、世界への挑戦状

LCTRは、物理学における二つの不正を告発する。

- 従来の物理学は、物理的に構成していない時間を、法則や計算の前提として使っている。
- 従来の時間生成論すべては、これから生成するはずの時間を、出発点の部品に暗黙に含めている。

LCTRは、非時間的な物理入力から時間を構成する手順と検証資料を公開し、世界に向けて挑戦状を出している。

先に成功した理論があるなら、その理論を教えてください。LCTRの部品に時間の混入が見つかったら、その箇所を指摘してください。構成にほかの誤りが見つかった場合も、指摘してください。動画でも、記事でも、論文でも、お好きな媒体で、この挑戦に答えていただけたら幸いです。

**[物理学への告発、世界への挑戦状を読む](https://tsuda-naoaki.github.io/lctr/world-challenge/)**

## An Indictment of Physics, a Challenge to the World

LCTR accuses physics of misconduct on two counts:

- Physics uses time as a premise in its laws and calculations without physically constructing it.
- All earlier theories of time generation implicitly include the time they are supposed to generate in their starting components.

LCTR publishes its procedure for constructing time from nontemporal physical inputs, together with verification materials, and issues a challenge to the world.

If an earlier theory has succeeded in doing this, please tell me about it. If you find time already present in LCTR’s components, please point out where. If you find any other error in the construction, please point that out as well. I would appreciate your response to this challenge in whatever medium you prefer—a video, an article, or a paper.

**[Read An Indictment of Physics, a Challenge to the World](https://tsuda-naoaki.github.io/lctr/world-challenge/en.html)**
